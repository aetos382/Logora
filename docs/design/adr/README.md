## 状態

| 状態 | 意味 |
| --- | --- |
| 提案 | PR で議論中。まだ従う必要はない。 |
| 採用 | 現在有効。実装はこれに従う。 |
| 却下 | 検討したが採らなかった。記録として残す。 |
| 置換 | 後続の ADR に置き換えられた。置換先へのリンクを持つ。 |

決定を変えるときは既存の ADR を書き換えず、新しい ADR を起こして相互にリンクする。
手順は [進め方](../process.md) にある。
