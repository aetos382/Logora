# ADR-0001: コードネームを Logora とする

- 状態: 採用
- 日付: 2026-09-10

## 背景

リポジトリ名、ルート名前空間、CLI コマンド名の基礎となる名前が必要だった。
既存の英単語ではなく、かつ英語として読みづらくない造語を求めた。

当初は diary（ラテン語）・logos（ギリシャ語）・blog（英語）を混ぜる案を検討したが、
語源が複数言語にまたがってちぐはぐになり、混ぜ切ると `dialog` のような既存語に衝突する見込みだった。

## 決定

**Logora** を採用する。語源はギリシャ語の logos（語・記述）に `-ora` を付した造語で、単一言語に統一されている。

- CLI コマンド: `logora`
- ルート名前空間: `Logora`

## 理由

- 語源が 1 言語に統一されており、由来を一貫して説明できる。
- 6 文字で打ちやすく、読みが揺れにくい。
- blog / log と響きが通じるため最初の用途（ブログ）を想起させつつ、汎用ジェネレーターの名前としても成立する。
- NuGet に `Logora` は存在しない。

## 影響

GitHub に `Logora` という organization が既に存在する（市民参加プラットフォーム系）。
自分のアカウント配下でのリポジトリ作成には支障がないが、公開前に商標を確認する。
